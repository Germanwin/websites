# Web Design — визуальный слой, который продаёт

База: `/Users/hermmoment/coding/websites/site-system/knowledge-base/04-дизайн/`

Материал из модуля «Дизайн-упаковка бренда» (Grind University) + приёмы визуального
языка конверсии из уроков по сайтам.

## Принцип

Дизайн на продающем сайте — не украшение, а **усиление иерархии смыслов**.
Поэтому:

- Порядок работы всегда: **смыслы → прототип → дизайн**. Начинать с дизайна и потом
  менять смыслы — долго, дорого и хуже по конверсии.
- **У каждого пикселя есть бизнес-задача.** Он либо пустой (чтобы не отвлекать),
  либо несёт смысл.
- **Правило слона:** размер элемента пропорционален его влиянию на конверсию.
- Красивый ≠ конверсионный. Референсы берём из практики, а не из портфолио-галерей.

## Ключевые правила

**Композиция**
- 7 принципов: баланс, иерархия, акцент, пропорции, ритм, симметрия/асимметрия, единство
- 12-колоночная сетка, контент 960–1200 px внутри фрейма 1440–1920
- Шаг отступов 8 px: `4·8·12·16·24·32·48·64·96·128`
- Правило близости: внутри блока отступы меньше, чем между блоками

**Цвет**
- Один фирменный цвет, а не пять равных
- **Правило 10%:** акцентный цвет (CTA) — максимум 10% площади экрана
- Поля ввода всегда белые
- **Белый фон конвертит лучше тёмного** — текст читается легче
- Контраст текста ≥ 4,5:1
- Плохая палитра — та, что убивает читаемость; неон+неон и «цыганская свадьба»

**Типографика**
- Основной текст — без засечек, ≥16 px, line-height 1,4–1,6
- Максимум 2 гарнитуры; в паре только один шрифт акцентный
- Самый безопасный приём: одна гарнитура, разные веса
- Длина строки 50–75 символов, выравнивание по левому краю
- **Жирным** не более 3–4 слов подряд

**Что убивает конверсию**
Огромная шапка · слоганы и общеизвестные цитаты · сток вместо реальных фото ·
слайдеры и карусели · тёмный фон под длинным текстом · pop-up на мобильных ·
кривая вёрстка и белые полосы · загрузка дольше 3 секунд

**Что её даёт**
Контрастная объёмная кнопка с подсветкой · белые поля ввода с подписью сверху ·
репортажные фото процесса и результата · стрелки, ведущие взгляд · выгоды
иконкой + заголовком + пояснением · визуализированный лид-магнит (коробка, каталог) ·
спойлеры вместо слайдеров · sticky-CTA на мобильных
