База знаний из курса: модули «UX/UI Дизайнер» (дизайн-упаковка бренда + уроки по
сайтам Владимира Сургая) и «Интернет-маркетолог» (Основы + Digital PRO).

## Как работать

1. Определи этап (таблица ниже) и **прочитай нужные файлы базы перед ответом** —
   там конкретные формулы, цифры и формулировки, а не общая теория.
2. Никогда не начинай с дизайна. Порядок всегда:
   **исследование → смыслы → оффер → прототип → дизайн → сборка → аналитика**.
3. Если данных о ЦА и фактов компании нет — сначала задай вопросы брифа или явно
   помечай допущения. Тексты без анализа аудитории писать нельзя.
4. Проси артефакт — отдавай **готовый документ**: прототип со всеми текстами,
   таблицу анализа, ТЗ дизайнеру, HTML. Не пересказ методики.
5. Перед выдачей прогоняй результат по соответствующему чек-листу.
6. Для визуальной реализации (компоненты, палитры, стек) подключай скилл
   **`ui-ux-pro-max`**. Для продажи услуги клиенту — **`sales-machine`**.

## Ключевые факты (держать в голове всегда)

- **4 ножки стола:** цепляющий заголовок → лёгкий заманчивый CTA → доверие →
  работоспособная вёрстка. Слабая ножка — бюджет на трафик сгорает.
- **Первый экран смотрят 100%, второй — 20–30%.** Всё главное на первом.
- **Заголовок — главный рычаг.** Смена оффера даёт ×2–8 без редизайна.
- **Правило слона:** размер элемента ∝ его влияние на конверсию. Самый крупный — оффер.
- **Формула идеальной выгоды:** `<польза в цифрах> за счёт <свойства>`.
  Цифры некруглые, не больше одного нуля.
- **Факты, а не мнения.** «Индивидуальный подход» → «прораб присылает фото и видео
  каждый день в 18:00».
- **Правило 5 000 ₽:** заполняя форму, человек психологически платит 5 000 ₽ —
  твой следующий шаг должен столько стоить.
- **CTA нестрессовый:** не «Купить», а рассчитать / подобрать / получить / попробовать.
  «Оставить заявку» 1,5% → «Подобрать лучшие туры» 5,4%.
- **Надпись на кнопке = заголовок формы.**
- **Правило 10%:** акцентный цвет занимает не больше 10% площади экрана.
- **Квиз:** 4–6 вопросов, от простого к сложному, ползунки вместо ввода,
  вариант «не знаю», вопрос-прокладка перед телефоном, **только телефон**.
- **Мобильная версия:** 10–12 блоков, один блок = один экран, интерактив под палец,
  sticky-кнопка снизу, спойлеры вместо слайдеров, светлый фон.
- **Белый фон конвертит лучше тёмного** — текст читается легче.
- **Формы захвата каждые 2–3 блока и разные**, если блоков больше 8.
- **Никогда не презентуй ПК и мобильную версию одновременно** — вдвое больше правок.
- Средняя конверсия сайтов 1–2%; хороший лендинг 5%+; лид-магнит до 50%, но лиды холодные.
- ROMI считается хорошим **от 200%**. Бизнес живёт, пока CAC < LTV.

## Типовые задачи

**«Сделай сайт для <ниша>»** → идти по `playbooks/сайт-за-неделю.md`.
Если вводных мало — задать блок вопросов из `templates/бриф-сайта.md`, затем
собрать смысловую карту и прототип. Не выдумывать цифры за клиента: помечать
`<уточнить у клиента>` или ставить правдоподобные и явно об этом сказать.

**«Напиши оффер»** → выбрать формулу из 8 по типу бизнеса, выдать 5–10 вариантов,
каждый по формуле идеальной выгоды, с пометкой, какие цифры надо подтвердить.

**«Проверь мой сайт»** → `playbooks/аудит-чужого-сайта.md` + чек-листы.
Считать эффект в деньгах через декомпозицию.

**«Собери страницу кодом»** → сначала прототип со смыслами, затем мини-гайдлайн,
затем реализация. Держать: 12 колонок, контейнер 1140–1200 px, шаг 8 px,
LCP ≤ 2,5 с, sticky-CTA на мобильных, цели аналитики на все действия,
галочка согласия на обработку ПД.
