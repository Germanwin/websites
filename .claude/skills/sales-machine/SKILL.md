## Ключевые факты (держать в голове)

- **Продавать связку «сайт + Яндекс.Директ»**, а не сайт отдельно: разовый чек + ежемесячное ведение.
- **Стартовые вилки:** сайт 20–50 тыс. ₽ · ведение рекламы 20–50 тыс. ₽/мес ·
  комплекс 40–100 тыс. ₽/мес. Цель — 3–5 клиентов на ведении = 100–150 тыс. ₽/мес.
- **По телефону не продаём услугу** — продаём следующий шаг: аудит, консультацию, встречу.
- **Цену называем как можно позже**, после брифа.
- **Сначала называем удобные себе условия**, потом отступаем. Обратно дороги нет.
- **Воронка:** ~200 касаний → ~7 встреч → 1–2 клиента. 28 отказов из 30 — норма.
- **Постоянство важнее объёма:** 2 звонка каждый день лучше, чем 40 раз в месяц.
- **Продавать нужно ЛПР.** Секретарь — не цель, цель — выход на руководителя.
- **Выбрать 2–3 канала** из 16, а не распыляться.
- **Нишевание кратно повышает конверсию** любого скрипта.

## Обновление базы

Новые материалы (архив, папка, видео, аудио, документ):

```bash
cd /Users/hermmoment/coding/websites/sales-system
./scripts/ingest.sh <путь> [имя-коллекции]
```

Скрипт распаковывает архив с починкой кодировки имён, извлекает аудио из видео,
транскрибирует локально (whisper.cpp + Metal), разбирает PDF/PPTX/XLSX/DOCX,
делает OCR презентаций-картинок (rus+eng).

После этого прочитай новые файлы в `03-transcripts/`, `02-docs-text/`, `04-slides-ocr/`
и **дополни существующие разделы базы**, а не создавай дубли. Свободные заметки
пользователь может складывать в `knowledge-base/inbox/` — их тоже разнеси по разделам.

При добавлении знаний соблюдай формат базы: в шапке файла — источник (модуль, урок, файл),
внутри — практика и конкретика, в конце — блок «Связанные материалы» со ссылками `[[имя-файла]]`.

## Границы

- Не выдавать чужие кейсы за кейсы пользователя.
- Не обещать клиентам гарантированные цифры результата — гарантируется процесс.
- Массовые рассылки — только по открыто опубликованным деловым контактам;
  помнить про маркировку рекламы и закон о персональных данных
  (`08-юридическое/правовые-основы.md`).
- Приёмы обхода секретаря вроде «я из Яндекса» — предупреждать о риске:
  курс сам подчёркивает, что обман вскрывается и убивает сделку.
