# База знаний: продажа услуг маркетинга и сайтов

Структурированные знания из курса «Модули по заработку» (Grind University):
6 ч 38 мин видео, 35 презентаций, 24 текстовых документа, готовые шаблоны КП, аудитов,
смет и клиентской базы. Плюс архив «доп. материалы»: реальные КП и презентация агентства
с 9 кейсами, смета/медиаплан/план-факт, CRM и клиентская база, чек-лист встречи,
тарифная сетка, два скринкаста с разбором КП и презентации.

**Как пользоваться:** просто спроси Claude — «как найти первого клиента»,
«составь КП для клиента X», «что ответить на возражение про дорого».
Claude сам подтянет нужные разделы через скилл `sales-machine`.

Ссылки на первоисточник есть в шапке каждого файла базы — можно поднять оригинал.

## Как добавить новые материалы

```bash
cd /Users/hermmoment/coding/websites/sales-system
./scripts/ingest.sh /путь/к/архиву-или-папке-или-файлу [имя-коллекции]
```

Скрипт сам: распакует архив (чинит кодировку имён), вытащит аудио из видео,
транскрибирует локально через whisper.cpp, разберёт документы, прогонит OCR по презентациям.

Потом скажи Claude: **«обнови базу знаний из новых материалов»**.

Быстрые заметки без обработки можно кидать в `knowledge-base/inbox/` —
Claude разложит их по разделам при следующем обновлении.
