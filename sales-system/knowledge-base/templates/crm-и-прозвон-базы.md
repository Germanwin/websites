## 1. Структура CRM-таблицы клиента

| Колонка | Что в ней |
|---|---|
| № | порядковый номер обращения |
| Дата | когда пришла заявка |
| **Источник** | Директ / РСЯ / таргет / карты / сарафан — **без этого вся аналитика бессмысленна** |
| Имя | |
| Телефон | |
| **Этап продаж** | новый → дозвонились → консультация → записан → приехал → оплатил → отказ |
| Партнёр / менеджер | кто вёл |
| **Стоимость** | сумма сделки, если купил |
| **Комментарий** | почему купил или почему нет — дословно |
| Повторный обзвон | дата следующего касания |

Минимальный рабочий вариант делается в Google Sheets за 20 минут. Полноценная
amoCRM/Битрикс — это уже отдельная платная услуга внедрения.

## 2. Зачем маркетологу лезть в CRM клиента

Три вещи, которые нельзя получить из Метрики:

1. **Реальная конверсия из заявки в деньги.** Метрика покажет 100 заявок, CRM покажет,
   что 40 из них — не дозвонились, а купили 6.
2. **Доказательство, что дело не в трафике.** Когда клиент говорит «заявки нецелевые»,
   таблица с комментариями отвечает точно: часть отказов — цена, часть — работа мастера,
   часть — нецелевой запрос. Это защищает твой бюджет и продлевает контракт.
3. **Материал для сайта.** Комментарии из CRM — готовые возражения, которые надо
   отработать блоками на лендинге.

## 3. Банк реальных причин отказа

Из прозвона 106 обращений автосервиса. Ценность не в самих фразах, а в том, **как они
группируются** — эта же картина повторяется почти в любой услуге.

**Цена и её обоснование** (самая частая группа)
- «Не устроила цена — 4 500 ₽» · «Не устроила цена — 14 500 ₽»
- «Не устраивает цена диагностики 2 000 ₽»
- «Ремонт стоит дороже, чем новая коробка»
- «Не смог назвать конкретную цену. Цена изменялась»
- «Не назвали цену»
→ **Лечится сайтом:** открытый прайс, калькулятор, вилка «от–до», объяснение,
из чего складывается цена. → [Разбор лендингов, KovroClean и «Вкус»](../../../site-system/references/разбор-22-лендингов.md)

**Работа менеджера / мастера**
- «Не понравилось общение с мастером, возможно, перезвонит»
- «Не понравилось общение с мастером. Не смог назвать конкретную цену»
- «Станислав не убедил приехать» · «Станислав по WhatsApp так и не ответил»
- «На конкретное время не приехал. В другом сервисе дали развёрнутую консультацию»
- «Путаница адресов»
→ **Это не маркетинг.** Но именно это надо показать клиенту цифрой, иначе виноватым
будет трафик.

**Ушёл к конкуренту**
- «В другом сервисе дали развёрнутую консультацию»
- «За 800 ₽ провели диагностику в другом СТО, оказался датчик»
- «Отдал в другой сервис» · «Решил взять готовый АКПП в другом СТО»
- «Сделал у знакомых»
→ **Лечится оффером и скоростью ответа**, а не бюджетом.

**Решил сам / проблема отпала**
- «Разобрался сам» · «Сам всё поменял» · «Решил проблему»
- «Ремонт или консультация уже не нужна» · «Уже продали машину»
- «Была оказана консультация по телефону» — **консультация состоялась, деньги нет**
→ Признак того, что нет продукта на «лёгкий вход»: платная диагностика, пакет,
абонемент.

**Не дозвонились / звонил не тот**
- «Звонил не он, наверное сын» · «Заявку не оставлял» · «Не звонил»
→ Проверить качество трафика и форму: нет ли случайных кликов, работает ли
подтверждение номера.

**Отложенный спрос — самая ценная группа**
- «Вернётся из командировки и будет заниматься проблемой» → через месяц: «уже сделал»
- «Пока вопросом не занимался» → через год всё ещё в базе
- «Ждёт появления явного дефекта»
- «Сейчас в командировке, готов притащить машину на эвакуаторе»
- «Сейчас КПП полностью сломалась и готов получить консультацию»
→ **Здесь лежат бесплатные деньги.** См. ниже.

**Страх и статус**
- «Испугался BMW-центра» · «Не стали ехать из-за БМВ»
→ Клиент решил, что услуга не для него. Лечится блоком «работаем с любыми марками» /
«не только премиум».

## 4. Прозвон отказников — быстрые деньги без бюджета

Самый недооценённый инструмент из таблицы: в базе почти любого бизнеса, который работал
хотя бы полгода, лежат сотни «нет» — и часть из них давно превратилась в «да».
В примере видно прямо: «пока не занимался» → через полгода «уже сделал» — **у конкурента**.

**Как продать это клиенту:** «Дайте вашу базу заявок за прошлый год. Я покажу, сколько
там живых денег, — и вам это ничего не стоит, кроме времени менеджера».

**Как делать:**
1. Выгрузить все заявки за 6–12 месяцев со статусом «отказ» / «не купил».
2. Отсеять группы «решил сам» и «купил у конкурента» — они холодные.
3. Прозванивать «отложенный спрос» и «цена» — это тёплая база.
4. Заход: не «вы оставляли заявку», а **новость + повод**: «У нас появилась рассрочка /
   изменилась цена / освободился мастер на этой неделе. Вы обращались по поводу АКПП —
   вопрос ещё актуален?»
5. Всё фиксировать в ту же CRM с датой следующего касания.

**Это же работает и для тебя самого:** твоя [клиентская база](клиентская-база.md) —
такой же список отказов. Клиент, который в марте сказал «сейчас нет бюджета», в сентябре
часто говорит «давайте». → [Быстрые деньги](../playbooks/быстрые-деньги.md)

## 5. Что автоматизируется

| Процесс | Чем снять с себя |
|---|---|
| Заявка → строка в таблице | Вебхук формы (Tilda/Flexbe/Marquiz) → Google Sheets / amoCRM |
| Источник заявки | UTM-метки в скрытых полях формы + коллтрекинг для звонков |
| Напоминание о повторном обзвоне | Колонка «Повторный обзвон» + фильтр по дате + напоминание |
| Сводка по источникам | Сводная таблица: заявки, продажи, выручка по каждому источнику |
| Прослушивание звонков | IP-телефония с записью — входит в пакет «усиление продаж» |

Полный список процессов → [Автоматизация](../playbooks/автоматизация.md).
