Инструкция для создания посадочной страницы на flex.be 
Шаг 1. Заходим на сайт flex.be 
Шаг 2 . Нажимаем “Попробовать бесплатно”
Шаг 3. Регистрируем учетную запись
Шаг 4. После регистрации на сайте нажимаем создать  “Квиз” 
Шаг 5. Знакомство “Как работает Flexbe”
Шаг 6. Знакомство с интерфейсом конструктора - страницы,заявки, аналитика, настройки 
6.1. Страницы. В данном разделе можно копировать страницы.
Нажимаем “Страницы”→ Три точки → Дублировать → Снова заходим в раздел страницы → Смотрим результат 
Шаг 7.Создаем логотип, слоган,контакты  на главной странице.
Настройки логотипа → Конструктор логотипа→ Создаем свой логотип 
Далее добавляем слоган, контакты и кнопку обратного звонка
7.1. На кнопку обратного звонка необходимо создать форму
Нажимаем на шестеренку →Выбрать окно→ Добавить окно → Стандартная форма → Создать → Редактируем под себя
