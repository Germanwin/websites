Как сделать Квиз на  flex.be 
Шаг 1. Нажимаем на настройки кнопки,где указана ваша стоимость  (см.фото)
Откроется конструктор редактирования. Перед редактированием вы должны знать, какие вопросы вы будете задавать, чтобы выявить потребности клиента
Как сделать это технически? Нажимаем на шестеренку 
Важно : Если это услуги,которые не требуют дополнительной визуализации, то картинки можно не использовать (здесь по желанию ) 
В остальных случаях можно использовать 2-3 варианта полей
Нажимаем на вопрос и начинаем редактировать  
Редактируем вопрос исходя из запроса. Далее сохраняем вопрос. Клиент не будет видеть строку с названием поля   
Создаем необходимое количество вопросов 
Создание контакта в два этапа
Задаем вопрос “Куда вам удобно получить расчет”
Вопрос → Галочка → Редактируем вопрос → Сохранить 
2.Настраиваем  поле с номером телефона. Не забудьте указать доп.настройки. Здесь клиент уже будет видеть название поля 
Выбираем стиль  кнопки. Квиз готов 
Шаг 2. Создаем страницу “Спасибо за заказ/заявку”
Заходим в раздел страницы → Создать страницу→ Пустая страницы → Настройка страницы →  Пишем заголовок и адрес страницы → Сохранить и закрыть  
После закрытия нажимаем на плюс и выбираем раздел контент
Выбираем указанную страницу
Начинаем оформлять страницу
Приступаем к редактированию кнопки. Меняем заголовок и добавляем файл на скачивание
Далее вы можете добавить изображение или видеообращение руководителя. Сохраняем изменения 
Шаг 3. Возвращаемся на главную страницу → Кнопка “узнать списание долгов”→ Настройки → Редактировать → Настройки → Результаты → Выбрать окно → Перейти  по ссылке → Выбрать страницу→ Добавляем страницу “Спасибо”
 Настройки→Редактировать
Настройки 
Результаты 
Выбрать окно → Перейти  по ссылке → Выбрать страницу→ Добавляем страницу “Спасибо”. Готово 
Шаг 4. Меняем фоновое изображение
Нажимаем на капельку
Загрузить 
Выбираем подходящее изображение и загружаем фон. По желанию можете его отредактировать
