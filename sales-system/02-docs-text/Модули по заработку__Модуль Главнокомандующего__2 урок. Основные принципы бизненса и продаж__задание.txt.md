# Модули по заработку/Модуль Главнокомандующего/2 урок. Основные принципы бизненса и продаж/задание.txt

1 Задание.
Предугадай и выпиши 5–10 опасений/возражений клиентов в момент переговоров с вами. (Это могут быть прошлые, нынешние или будущие клиенты.) После этого на каждый пункт выпиши по 2–3 отработки этих опасений/возражений, которые помогут тебе их преодолеть.

2 Задание.
Аргументируй, почему именно эти опасения ты считаешь основными при переговорах с клиентами.
+ По желанию обсудите в вашем учебном чате те опасения, которые вы выписали, и их отработку.
