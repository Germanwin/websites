Настройка целей 
Шаг 1 . Заходим в Яндекс метрику и добавляем счетчик ( вставляем адрес ссылки готового адреса) → Выключаем автоматические цели → Включаем вебвизор, карта скроллинга, аналитика форм → Создать счетчик 
Далее переходим снова на главную страницу Яндекс метрики, нажимаем на готовый счетчик 
Копируем идентификатор Яндекс метрики 
Возвращаемся на сайт Flexbe → Настройки → Аналитика → Вставляем номер счетчика → Включаем Вебвизор→ Сохранить 
Шаг 2. Настройка целей на квиз 
Переходим на главную страницу → Нажимаем на рассчет стоимости (настройки)→ Нажимаем на вкладку Цели→ Настраиваем цель на открытие квиза    
Копируем Основную цель 
Переходим в Яндекс метрику - цели 
Добавить цель → Java Script - Событие → Вставляем идентификатор → Называем цель “Открыл квиз” → Добавить цель → Готово 
Шаг 3. Возвращаемся на страницу flexbe→ Открываем квиз → Настройки→ Результаты → Копируем список целей order_done 
Если человек пройдет квиз, укажет свой номер телефона и отправит его , то сработает событие order_done 
Шаг 4 . Создаем новую цель в Яндекс метрике по примеру
Java Script - Событие → Вставляем идентификатор → Называем цель “Лид с квиза ” → Добавить цель → Готово  
Шаг 5. Узнаем, на каком вопросе квиза застревает человек 
Вариант 1. Смотрим статистику квиза. Узнаем,на каком этапе,какая статистика  
Вариант 2. Настраиваем цель в Яндекс метрике 
Открываем первый вопрос квиза → Доп.настройки → Отправлять цель в систему аналитики → Название цели (например, step 1)
Шаг 6. Добавляем цель в Яндекс метрику
Javascript - Событие → Вставляем идентификатор → Называем цель “Прошел первый  вопрос  ” → Добавить цель → Готово  
По аналогии проделываем так со всеми вопросами, кроме вопроса указания  номера телефона   
Шаг 7. Форма “Перезвони мне”
Графа “Перезвони мне” имеет к КНОПКЕ. Нам нужно создать цель на отправку формы,а не на клик 
Открываем форму “Перезвони мне ” → Редактировать → Настройки 
Настраиваем форму 
Пишем новое название цели  
Переходим в Яндекс метрику→  Java Script - Событие → Вставляем идентификатор → Называем цель “Обратный звонок  ” → Добавить цель → Готово  
Если вы захотите настроить цель на клик по номеру телефона
Заходим в Яндекс метрику → Добавить цель → Клик по номеру телефона → Редактируем под себя (все номера телефона или конкретный номер телефона) → Добавить цель
