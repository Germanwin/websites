Настройки домена и подключение мобильной версии на  flex.be 
Шаг 1 . Настройка домена → Настройки → Раздел домен → Добавить домен → Проверить 
Вы можете использовать существующий домен или зарегистрировать новый прямо в FLEXBE 
Шаг 2. Создаем мобильную версию страницы 
Страницы → Главная страница→ Три точки → Дублировать  → Адрес страницы “ mobile”→ Дублировать  → Мобильная версия готова 
Переходим в режим мобильной версии и смотрим результат
