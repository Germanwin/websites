# Что нужно положить в assets, чтобы сайт стал боевым

Вёрстка уже рассчитана на эти файлы. Пока файла нет, на его месте показывается
подпись с описанием нужного кадра, битых картинок не появляется —
`onerror` убирает пустой `<img>`. Как только файл лёг по своему пути, он подхватывается
без правок кода.

## 2. Видео — `assets/video/*.mp4`

| Файл | Что снять | Длина |
|---|---|---|
| `glubina-1-4.mp4` | Бурение лунки, рулетка в лунке на отметке 1,4 м, щебневая подушка, заливка бетона. Без монтажа и музыки | 40–60 сек |
| `kak-prohodit-zamer.mp4` | Как проходит замер: приезд, проба грунта буром, палитра RAL, три распечатанные сметы. Для страницы «Спасибо» | ~2 мин |

H.264, 1920×1080, до 8 Мб. Это самое сильное доказательство на всём сайте:
весь оффер держится на глубине 1,4 м, и её надо показать, а не пообещать.

## 3. Документы — `assets/docs/*.pdf`

`dogovor-obrazec.pdf`, `garantiya.pdf`, `sertifikat-metall.pdf` — с них снимаются
превью для блока «Документы». Персональные данные в образце договора замазать.

## 4. Шрифт

`assets/fonts/manrope-cyrillic.woff2` и `manrope-latin.woff2` уже лежат — переменный
Manrope, 40 Кб на двоих. Google Fonts намеренно не используется: в РФ он отдаётся
нестабильно и блокирует рендер.

## 5. Что заполнить в коде

В начале `<script>` в `index.html` — объект `CONFIG`:

| Поле | Что поставить |
|---|---|
| `leadEndpoint` | URL приёмника заявок: вебхук CRM, Telegram-бот или `/lead.php`. Пока пусто — заявки уходят в консоль браузера и **никуда не сохраняются** |
| `metrikaId` | Номер счётчика Яндекс.Метрики. Пока `0` — счётчик не подключается, цели пишутся в консоль |
| `tg` | Реальный аккаунт Telegram (сейчас заглушка `t.me/goodzabor_spb`) |
| `wa` | Номер WhatsApp, если он отличается от офисного |
| `promoUntil` | Дата окончания акции. Прошла — таймер сам скрывается, вечного «до конца недели» больше нет |
| `slots` | Сколько слотов на замер осталось на неделе. Ставится руками — цифра должна быть правдой |

Тот же номер счётчика продублировать в `thanks.html` (`METRIKA_ID`) — по этой странице
ставится цель «лид».

В `privacy.html` — реквизиты юрлица в пунктах 1.1 и 9.
