## Обязательные правила

- Оффер — самый крупный элемент первого экрана (правило слона)
- Шапка ≤ 10% высоты первого экрана
- Кнопка CTA: контрастная, объёмная, подсветка при наведении
- Поля ввода — белые, подпись **над** полем
- Фон монохромный, светлый; тёмный только по согласованию
- Один информационный блок = один смысл
- Никаких слайдеров — спойлеры
- Фото только реальные, не сток. Список нужных съёмок: …
- Контраст текста к фону ≥ 4,5:1
- Мобильная версия: интерактив в зоне большого пальца, sticky-кнопка снизу
