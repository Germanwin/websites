# Типографика

## Что учитывать при выборе шрифта

1. **Читаемость.** Каким бы красивым ни был дизайн символов — если невозможно
   прочитать, шрифт не годится
2. **Концептуальность.** Шрифт должен соответствовать смыслу: брутальный барбершоп
   не оформляют шрифтом из детских мультиков
3. **Гармония пары.** Готический шрифт не сочетается со шрифтом из Minecraft

## Виды

| Семейство | Пример | Где |
|---|---|---|
| С засечками (serif) | Roboto Serif | Заголовки, премиум, редакционный стиль |
| Без засечек (sans-serif) | Inter, Arial | **Основной текст на сайтах** |
| Моноширинные | Courier New | Код, цифры, техно-эстетика |
| Декоративные / рукописные | — | Только акценты, никогда — текст |

**Для основного текста на сайте — шрифт без засечек.** С засечками читать
с экрана менее удобно; засечки придуманы для заголовков и печати.

## Как собрать удачную шрифтовую пару

1. **Стилистическая близость.** Если один — рукописный с завитушками, второй
   не может быть high-tech
2. **Только один акцентный.** В паре не может быть два ярких шрифта — всегда должен
   быть один спокойный, дополняющий
3. **Не больше двух шрифтов** в макете

### Рабочие пары

| Заголовок | Текст |
|---|---|
| Montserrat Bold | Roboto Flex Regular |
| Sofia | Montserrat Regular |
| Roboto Serif Bold | Lato Regular |
| Manrope Bold | Manrope Regular *(одна семья, разные веса — всегда безопасно)* |
| Helvetica Light | Arial Regular |

Самый надёжный приём для новичка: **одна гарнитура, разные начертания и веса**.

## Типографическая шкала

Строй кегли по модульной шкале (шаг 1,25 или 1,333):

```
H1   48–64 px   (мобильный 32–40)
H2   32–40 px
H3   24–28 px
Body 16–18 px   ← меньше 16 px основной текст не делаем
Small 14 px
```

- **Межстрочный интервал:** 1,4–1,6 для основного текста, 1,1–1,2 для крупных заголовков
- **Длина строки:** 50–75 символов. Длиннее — глаз теряет строку
- **Выравнивание:** больше трёх строк — только по левому краю. Никакой выключки
  по ширине на вебе

## Оформление текста на сайте — чек-лист

- [ ] Первые 3 слова абзаца — мини-заголовок: что-то новое и интересное
- [ ] **Жирным** — важные места, но не более 3–4 слов подряд
- [ ] Максимум ~140 символов и 3–4 строки в одном абзаце
- [ ] Больше трёх строк — выравнивание по левому краю
- [ ] Шрифт без засечек для основного текста
- [ ] Мало существительных в предложении, больше глаголов
- [ ] Слова в предложении начинаются с разных букв
- [ ] Нет сложных слов, особенно подряд
- [ ] Проверено на «воду» (text.ru/seo или аналог)

## Логотип из шрифта

Многие известные логотипы — это просто удачно набранный шрифт:
Instagram → Billabong, iPhone → Myriad Pro. Ключ — **чёткое композиционное
выравнивание** и правильные межбуквенные расстояния.
