# Цвет

**Колористика** — наука о цвете: как он влияет, что вызывает, как использовать.
В маркетинге цвет — главный инструмент создания атмосферы и эмоции.

## Эмоции и ассоциации

| Цвет | Ассоциации | Где работает |
|---|---|---|
| **Красный** | Страсть, энергия, аппетит, жажда, срочность | Еда, распродажи, акции, CTA |
| **Жёлтый** | Тепло, солнце, радость, хорошее настроение | Еда, детское, доступность |
| **Синий** | Надёжность, спокойствие, доверие, благородство | B2B, финансы, медицина, техника |
| **Зелёный** | Природа, жизнь, экология, здоровье, деньги | Эко, здоровье, финансы |
| **Фиолетовый** | Творчество, роскошь, креатив | Премиум, бьюти, образование |
| **Чёрный/графит** | Премиальность, строгость, сила | Люкс, авто, техника |

Цвет всегда вызывает эмоцию — с этим ничего не поделать, поэтому им надо управлять
осознанно.

## Цвет как идентификация

Один цвет может заменить логотип: Tiffany, Ferrari (запатентовали свой оттенок
красного), ЦИАН, Сбер. Если цвет последовательно повторяется во всех точках контакта,
он «садится» в голову аудитории.

**Практика:** у сайта должен быть один узнаваемый фирменный цвет, а не пять равных.

## Цветовой круг Иттена

Три уровня:
1. **Первичные** — синий, жёлтый, красный
2. **Вторичные** — смешение первичных: зелёный, фиолетовый, оранжевый
3. **Третичные** — оттенки

### Схемы подбора

| Схема | Как строится |
|---|---|
| **Комплементарная** | Цвет + противоположный на круге |
| **Контрастная триада** | Цвет + два соседа его противоположного |
| **Классическая триада** | Три цвета через равные промежутки (через 3) |
| **Аналоговая** | Три соседних цвета |
| **Тетрада** | Четыре цвета через каждые два |
| **Прямоугольная** | Цвет + через один + противоположные с другой стороны |

## Практическая палитра сайта

```
Фон              — белый / очень светлый нейтральный
Основной текст   — почти чёрный (#111–#222), не чистый чёрный
Вторичный текст  — серый достаточной контрастности
Фирменный цвет   — 1 шт., используется дозированно
Акцентный (CTA)  — контрастный, максимум 10% площади экрана
Поля ввода       — всегда белые
```

**Правило 10%.** Цвет кнопки CTA должен занимать не больше ~10% площади экрана.
Тогда его невозможно не заметить. Если акцентный цвет везде — акцента нет.

**Белый фон конвертит лучше всего** по A/B-тестам: на нём легче читается текст.
Тёмный выглядит премиальнее, но конвертит хуже.

## Что делает палитру плохой

- **Убитая читаемость текста** — главный критерий. Если текст плохо виден, палитра плохая
- **Несколько неоновых/кислотных цветов рядом** (неоново-розовый + неоново-зелёный) —
  глаза устают, хочется сбежать
- **Много ярких цветов сразу** — визуальный шум
- **Слишком близкие цвета** без контраста — макет «сливается»

> Плохих цветов самих по себе не бывает — как с лекарствами, всё дело в дозировке.

## Доступность

Проверяй контраст текста к фону: минимум **4,5:1** для основного текста и **3:1**
для крупного. Кнопка должна быть различима не только цветом (форма, размер, подпись).
