# Маркетинговая связка

## Определение

**Маркетинговая связка** — система из **канала трафика + конвертера**, которая
относительно устойчиво и предсказуемо приводит потенциальных клиентов.

У каждого действующего бизнеса есть своя связка.

## Примеры связок

| Трафик | Конвертер |
|---|---|
| Яндекс.Директ | Landing Page ← **самая популярная** |
| Реклама у блогера | Чат-бот + карточка товара |
| Ролик на YouTube | Сайт |
| Партнёры | Отдел продаж |
| Таргет ВК | Квиз-лендинг |
| Автовебинар | Лендинг-акция |

## Практический смысл для сайта

Сайт не существует в вакууме. Прежде чем проектировать, ответь:

1. **Откуда пойдёт трафик?** От этого зависит температура аудитории и ключевые слова
2. **С какой ступени лестницы Ханта приходят люди?**
3. **Какой конвертер уместен** — Атлант, квиз, лид-магнит?
4. **Что после конвертера?** Отдел продаж, чат-бот, цепочка писем?
5. **Совпадает ли обещание рекламы с заголовком сайта?** (принцип релевантности)

Если реклама обещает одно, а первый экран говорит другое — конверсия рухнет,
как бы хорош ни был сайт.

## Мультилендинг и гиперсегментация

Технология подмены **релевантного ключевого слова** (РКС) в заголовке под запрос
пользователя. Человек искал «ремонт MacBook Pro на M1» — видит в заголовке ровно эти
слова. Сервисы: Yagla и аналоги.
