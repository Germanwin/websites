# Лестница Бена Ханта: какой конвертер под какую стадию

Аудитория находится на разных стадиях осознанности. Один и тот же лендинг не может
работать для всех — под каждую ступень свой инструмент.

## Пять ступеней

| Ступень | Состояние клиента |
|---|---|
| 0. Нет проблемы | Не знает, что проблема существует |
| 1. Проблема неочевидна | Проблема есть, но не осознаётся |
| 2. Проблема очевидна | Ищет информацию, что с этим делать |
| 3. Выбор решения («примерка») | Сравнивает типы решений |
| 4. Выбор поставщика | Выбирает, у кого купить |
| 5. Покупка | Готов платить конкретному бренду |

## Инструменты по ступеням

### 1–2. Осознание проблемы
- Лид-магнит + воронка прогрева (например, первые 2 главы книги)
- Автовебинарная воронка
- Квиз-бот + воронка прогрева
- Креатив через боль

### 3. Выбор решения (примерка, поиск информации)
- **Квиз-бот с контентом + лендинг-Атлант**
- Лендинг-Атлант
- Квиз-лендинг 4-го поколения (можно в связке с Атлантом)
- Автовебинарная воронка (рискованно)
- Продающее видео
- Дожимы менеджерами в WhatsApp
- Ведение и продвижение контента в соцсетях

### 4. Поиск поставщиков
- **Мультилендинг-Атлант с акцией / квиз 4-го поколения** + лид-магнит на странице
  «Спасибо» + цепочка прогрева
- ЛИБО мультиквиз + лид-магнит на «Спасибо» + цепочка прогрева
- Дожимы менеджерами в WhatsApp

### 5. Срочно / решение о покупке конкретного бренда
- Всё из предыдущей ступени
- Страница оплаты / карточка товара
- Скрипты продаж
- Мозговой штурм: как максимально упростить покупку

## Пример на одном продукте (чехлы для чемоданов)

| Ступень | Что делаем |
|---|---|
| Проблема неочевидна | Креатив через боль (украли/испортили чемодан) |
| Проблема очевидна | Статья / лид-магнит о защите чемоданов от взлома |
| Выбор решения | Обзор чехлов, сравнение |
| Выбор поставщика | Лендинг с оффером, акция, отзывы, отстройка от конкурентов |
| Покупка | Страница оплаты (карточка товара) |

## Как применять при проектировании сайта

1. Определи, **с какой ступени приходит трафик** (контекст по коммерческим
   запросам = ступень 4; таргет по интересам = ступень 1–2).
2. Подбери тип конвертера под ступень ([Типы сайтов](../02-структура-и-смыслы/типы-сайтов.md)).
3. Если трафик холодный — между рекламой и лендингом должен быть прогрев, иначе
   лендинг «не работает» не по своей вине.
