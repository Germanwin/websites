# Виды трафика и Affinity Index

## Два принципиально разных подхода

### «Люди идут к нам» — горячий спрос

Человек внутри себя уже принял решение купить и ищет поставщика:

- Яндекс.Директ / Google Ads (поиск)
- Avito
- ЦИАН / Яндекс.Недвижимость
- Агрегаторы (компаний, специалистов, товаров)
- Маркетплейсы
- Реклама на картах, SERM/ORM
- SEO (смежно)

→ Ступень 4–5 лестницы Ханта. Конвертер: **лендинг-Атлант, квиз, мультилендинг**.

### «Мы идём к людям» — холодный спрос

Человек развлекается в интернете и видит нашу рекламу:

- Таргетированная реклама в соцсетях (VK, OK, Telegram Ads)
- Медийная реклама
- Реклама у блогеров / закупы в пабликах
- YouTube
- SMM, event-маркетинг
- CRM-маркетинг (работа с базой)
- Холодные звонки, SMS-рассылки

→ Ступень 1–3. Нужен **прогрев** перед конвертером: лид-магнит, контент,
автовебинар, чат-бот.

## 4 канала для старта

1. **Контекстная реклама** (Яндекс.Директ) — поисковая (текст) и баннерная в РСЯ
2. **Органический трафик** — SEO и соцсети
3. **Таргетированная реклама** в соцсетях
4. **Закупка рекламы у блогеров и лидеров мнений**

### Контекстная реклама

Настраивается по: поисковым запросам · ретаргетингу (кто был на сайте или совершал
действия) · базе контактов · интересам и параметрам · похожей аудитории (look-alike) ·
контенту сайта · автотаргетингу.

| ✅ Плюсы | ❌ Минусы |
|---|---|
| Самые горячие клиенты | Количество горячих запросов ограничено |
| Стабильный, предсказуемый результат | Большая конкуренция |
| Быстрый результат | Самый дорогой вид рекламы |
| Можно платить за конверсии | |

→ Конвертер: лендинг-Атлант, квиз, мультилендинг с подменой РКС.

### Таргетированная реклама

Настраивается по: ретаргетингу · базе контактов и подписчиков · интересам
и параметрам · похожей аудитории. Форматы: посты, истории, картинки, фото/видео.

→ Аудитория холоднее: нужен прогрев, лид-магнит или квиз с низким порогом входа.

## Метафора рыбалки

Рекламные каналы — озёра с рыбой. Наша реклама — снасти.
Задача — понять, водится ли наша рыба в этом море.

## Affinity Index (аффинитивность)

```
Affinity Index = Рейтинг площадки для целевой аудитории
                 ─────────────────────────────────────
                 Рейтинг площадки для всей аудитории
```

- **> 100%** — площадка «наша», ЦА концентрируется здесь сильнее среднего
- **< 100%** — на площадке нашей аудитории меньше, чем в среднем

Помогает выбирать каналы не по ощущениям, а по данным.

## Что это меняет для сайта

| Трафик | Первый экран | CTA |
|---|---|---|
| Горячий (поиск) | РКС дословно из запроса, цена/сроки/гарантия | Расчёт, подбор, КП |
| Холодный (таргет) | Боль/интрига, новизна | Лид-магнит, тест-драйв, квиз |
