# Фундамент конверсии: 4 ножки стола

> Источник: Сургай, «Максимум конверсии на сайтах», «Оформление первого экрана».

## Главная метафора

Маркетинг — это **углубление в рынке, куда стекает вода**. Задача — убрать всё,
обо что клиент может споткнуться или застрять. Плохой маркетинг выглядит как зона
отчуждения с колючей проволокой: до покупки доходят только самые мотивированные.
Хороший — как горка в аквапарке: человек не заметил, как стал клиентом.

**Практический смысл:** каждый раз, когда добавляешь на сайт элемент, спрашивай —
это ускоряет скатывание или создаёт препятствие?

## Четыре ножки стола

Сайт, который приносит деньги, стоит на четырёх ножках. Если хоть одна слабая —
бюджет на трафик сгорает впустую.

| № | Ножка | Что это значит |
|---|---|---|
| **1** | **Цепляющий заголовок (оффер)** | Сильнее всего влияет на конверсию. Смена заголовка даёт рост в 2–8 раз. Меняется без редизайна. |
| **2** | **Лёгкий и заманчивый призыв к действию** | Не «Купить», а «Получить подборку / расчёт / тест-драйв». Тоже меняется без редизайна. |
| **3** | **Сайт вызывает доверие** | Аккуратный точный дизайн, настоящие фото, блоки доверия. Рептильный мозг за долю секунды считывает «безопасно/скам». |
| **4** | **Работоспособная вёрстка** | Загрузка ≤ 3 сек, реальный телефон, заявки реально доходят, нет белых полос и наездов на всех устройствах и браузерах. |

Порядок влияния на конверсию: **заголовок → CTA → доверие → техника**.
Размер элемента на макете должен быть пропорционален его влиянию на конверсию
(«правило слона»): самый большой элемент первого экрана — оффер.

## Проверка перед запуском трафика

Не отправляй ни рубля рекламы, пока все четыре пункта не закрыты:

- [ ] Оффер по формуле идеальной выгоды, с цифрами, релевантен ключевому слову
- [ ] CTA нестрессовый, даёт ценность «на 5 000 ₽», кнопка контрастная
- [ ] Есть блоки доверия: реальные фото, факты, кейсы, гарантии, отзывы
- [ ] Сайт грузится ≤ 3 сек, телефон настоящий, тестовая заявка дошла на почту/в Telegram
- [ ] Проверено на реальном смартфоне, а не только в режиме адаптива браузера

## Куда смотреть, если конверсия просела

1. Заголовок — переписать по формуле, протестировать 2–3 варианта.
2. CTA — сделать шаг менее стрессовым, добавить ценность.
3. Первый экран целиком — прогнать по [чек-листу](../../checklists/первый-экран.md).
4. Техника — скорость, формы, мобильная версия.
