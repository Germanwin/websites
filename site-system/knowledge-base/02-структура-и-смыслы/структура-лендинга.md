# Структура лендинга: блоки доверия и блоки конверсии

Лендинг-Атлант — 15–20 экранов. Первый экран **захватывает**, остальные **утепляют**.
Порядок блоков подбирается под топ критериев выбора и возражений конкретной ЦА:
что важнее — то выше.

## Базовый скелет

```
 1. Первый экран (оффер + CTA + доверие + буллиты)
 2. Боль / проблема аудитории — «узнаёте себя?»
 3. Решение: что мы предлагаем и почему это работает
 4. Выгоды по формуле идеальной выгоды (иконка + заголовок + пояснение)
 5. ⚡ ФОРМА ЗАХВАТА №2 (квиз / калькулятор)
 6. Как мы работаем — этапы, сроки, прозрачность
 7. Кейсы / примеры работ / «до–после»
 8. ⚡ ФОРМА ЗАХВАТА №3
 9. Отзывы (живые, со скриншотами, с выделенным маркером ключевым)
10. Отстройка от конкурентов / сравнительная таблица
11. Гарантии и снятие страхов
12. Команда / производство / офис — реальные фото
13. Сертификаты, награды, клиенты-логотипы
14. Цены / тарифы / что входит
15. FAQ — прямая отработка возражений из анализа ЦА
16. ⚡ ФИНАЛЬНАЯ ФОРМА ЗАХВАТА + акция/дедлайн
17. Контакты, карта, реквизиты, политика конфиденциальности
```

**Правило форм:** если лендинг длиннее 8 блоков — форма захвата каждые **2–3 блока**,
и формы должны быть **разными**, подходящими по смыслу к соседнему контенту.
Одинаковые формы по всему сайту — ошибка.

## Блоки, повышающие доверие

| Блок | Как усилить |
|---|---|
| **Реальные фото процесса и результата** | Репортажная съёмка, а не сток. Мастер за работой, производство, офис |
| **Персональный менеджер** | «После старта закрепим за вами персонального менеджера, который будет на связи весь срок работ» |
| **Прозрачность процесса** | «Будем регулярно присылать фото и видео процесса», «прораб присылает отчёт каждый день в 18:00» |
| **Гарантии в цифрах** | «1 год гарантии на все комплектующие», «гарантия 25 лет от выцветания» |
| **Гарантия-компенсация** | «Доставим в срок или бесплатно», «выплатим 5 000 ₽ за каждый день просрочки», «найдёте дешевле — вернём разницу» |
| **Подменный фонд / страховка риска** | «Предоставим подменную кофемашину аналогичного качества на время ремонта» |
| **Отзывы** | Живые скриншоты из соцсетей, ключевое выделено маркером. Кликабельные, с именами |
| **Кейсы с цифрами** | Что было → что сделали → результат в деньгах |
| **Клиенты-логотипы** | Особенно узнаваемые бренды |
| **Сертификаты, награды, рейтинги** | «ТОП-100 франшиз по версии БИБОСС, 95 место», «4,6★ и 118 отзывов в Google» |
| **Компания в цифрах** | Лет на рынке, объектов, клиентов, единиц на складе |
| **Реквизиты и юрлицо в подвале** | Базовый признак нескамности |
| **Видео о компании** | На первом экране или отдельным блоком |

## Блоки, повышающие конверсию

| Блок | Механика |
|---|---|
| **Квиз / калькулятор** | Вовлечение + прогресс-бар; лучше всего, когда считает выгоду клиента |
| **Расчёт в 3 вариантах** | «Получите расчёт стоимости в 3-х вариантах + подарки» |
| **Лид-магнит** | Чек-лист, каталог, прайс, PDF-план — визуализированный |
| **Акция с дедлайном** | Таймер, «осталось 7 мест из 25», «скидка до 24.06» |
| **Подарки за заявку** | «Скидка 10% на повторный заказ + расчёт стоимости» |
| **Тест-драйв / КЭВ** | Бесплатное занятие, выезд мастера, тест на 3 недели |
| **Pop-up на выход** | На десктопе; на мобильных — избегать |
| **Sticky-кнопки** | Мобильные: «Позвонить» + «Оставить заявку» |
| **Кнопки мессенджеров** | WhatsApp / Telegram / VK по всему лендингу |
| **Callback-виджет** | «Перезвоним за 27 секунд» |

## Принцип релевантности

Одна услуга = одна посадочная = один оффер = один сегмент ЦА.
Не пытайся продать всё на одной странице — сделай несколько лендингов
([лендосайты](типы-сайтов.md#5-лендосайты-сетка-лендингов)).

## Морковка спереди и сзади

Два способа сформулировать посыл блока:

- **Морковка спереди** (мечта, цель): «Приходи лечить кариес, чтобы иметь красивую улыбку»
- **Морковка сзади** (боль, страх): «Приходи лечить кариес, чтобы не потерять зуб»

Обе работают. Выбор зависит от того, что сильнее у сегмента: стремление или избегание.
