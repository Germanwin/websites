# Чек-лист текста

Прогоняй через него любой текст на сайте, в КП, в рассылке.

## Смысл

- [ ] Текст **о клиенте**, а не о компании («Вы получите…», а не «Мы, наша компания…»)
- [ ] Нет вступления и прелюдии — с порога факты и выгоды
- [ ] Каждое обещание — **факт с цифрой**, а не мнение
- [ ] Цифры некруглые (не более одного нуля)
- [ ] У каждой выгоды есть «**за счёт чего**»
- [ ] Выгоды попадают в реальные критерии выбора из анализа ЦА
- [ ] Есть релевантное ключевое слово там, где нужно
- [ ] Написано языком аудитории, а не отраслевым жаргоном

## Форма

- [ ] Первые 3 слова абзаца — мини-заголовок с чем-то новым и интересным
- [ ] Абзац — максимум ~140 символов / 3–4 строки
- [ ] Короткие предложения, минимум запятых, «который/где/как» заменены точками
- [ ] Деепричастия заменены глаголами
- [ ] Иностранные и сложные слова упрощены (оптимизировать → улучшить)
- [ ] Нет двух-трёх сложных слов подряд
- [ ] Слова в предложении начинаются с разных букв
- [ ] Мало существительных, больше глаголов — и глаголы сильные
- [ ] **Жирным** выделено не более 3–4 слов подряд
- [ ] Больше трёх строк — выравнивание по левому краю
- [ ] Шрифт основного текста — без засечек
- [ ] Проверено на «воду»

## Усиление (по ситуации)

- [ ] Есть метафора или яркое сравнение вместо клише
- [ ] Глаголы усилены (болит → ноет, работает → ревёт)
- [ ] Для соцсетей: щепотка провокации, сильная фраза из литературы

## Быстрый тест

Прочитай текст вслух за 6 секунд. Понял ли посторонний человек:
что продают, кому, за сколько, чем это лучше и что делать дальше?
