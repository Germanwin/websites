# Аналитика: цели и метрики

Сайт без настроенных целей — это сайт, о котором ничего нельзя сказать. Настройка
целей делается **до** запуска трафика.

## Базовая настройка (Яндекс.Метрика + конструктор)

**Шаг 1. Счётчик**
1. Метрика → добавить счётчик, вставить адрес сайта
2. **Выключить автоматические цели**
3. **Включить:** Вебвизор, карта скроллинга, аналитика форм
4. Создать счётчик, скопировать идентификатор
5. Конструктор (Flexbe/Tilda) → Настройки → Аналитика → вставить номер → включить
   Вебвизор → сохранить

**Шаг 2. Цель «Открыл квиз»**
Кнопка расчёта → Настройки → Цели → скопировать основную цель →
Метрика → Добавить цель → **JavaScript-событие** → вставить идентификатор →
назвать «Открыл квиз».

**Шаг 3–4. Цель «Лид с квиза»**
Квиз → Настройки → Результаты → скопировать цель `order_done` →
Метрика → JavaScript-событие → назвать «Лид с квиза».
Событие срабатывает, когда человек прошёл квиз и отправил телефон.

**Шаг 5–6. Цели по шагам квиза** — чтобы видеть, где отваливаются
- Вариант 1: встроенная статистика квиза
- Вариант 2: у каждого вопроса → Доп. настройки → «Отправлять цель в систему
  аналитики» → `step_1`, `step_2`… → завести такие же цели в Метрике

Так видно **на каком вопросе застревает человек** — самый быстрый источник роста конверсии.

**Шаг 7. Форма «Перезвоните мне»**
Цель ставится на **отправку формы**, а не на клик по кнопке.
Отдельно можно завести цель «Клик по номеру телефона».

## Минимальный набор целей на лендинге

| Цель | Зачем |
|---|---|
| Открыл квиз / калькулятор | Верх микроворонки |
| Прошёл шаг 1, 2, 3… | Где отваливаются |
| Лид с квиза (`order_done`) | Основная конверсия |
| Отправил форму обратного звонка | Второй канал заявок |
| Клик по номеру телефона | Звонки напрямую |
| Клик по мессенджеру | Заявки в WhatsApp/Telegram |
| Скроллинг 75% | Качество трафика и интерес |

## Метрики, за которые отвечает сайт

```
CTR                = клики / показы            (реклама)
Конверсия сайта    = заявки / посетители       ← зона сайта
CPL                = бюджет / заявки
Конверсия в продажу= продажи / заявки          (отдел продаж)
CPO                = бюджет / продажи
ROMI               = (доход − расходы) / расходы   ← хорошо от 200%
CAC < LTV          — условие существования бизнеса
```

Ориентиры: средняя конверсия сайтов по интернету — **1–2%**; хороший лендинг — **5%+**;
квиз-лендинг выше; лид-магнит — до 50% (но лиды холодные).

## Что смотреть в Вебвизоре и картах

- **Карта скроллинга** — до какого блока вообще доходят
- **Аналитика форм** — на каком поле бросают
- **Вебвизор** — записи сессий: где мечутся, что не находят
- **Клики по некликабельному** — люди ждут интерактива там, где его нет

## A/B-тесты и гипотезы

Порядок перебора гипотез — по силе влияния:

1. **Заголовок / оффер** — до ×8 по конверсии
2. **CTA**: формулировка, нестрессовость, ценность
3. **Первый экран целиком**: фото, буллиты, композиция
4. **Форма**: количество полей и вопросов, порядок
5. **Блоки доверия**: что выше, что ниже
6. **Цвет и размер кнопки**

**Правила:**
- Меняй **одну переменную** за раз
- Дожидайся значимого объёма, а не 20 визитов
- Записывай гипотезы и результаты — это твой актив на следующие проекты
- Ищи слабое место **по всей воронке**: если конверсия из звонка в запись 20%
  вместо 80% — проблема не в сайте, а в отделе продаж
