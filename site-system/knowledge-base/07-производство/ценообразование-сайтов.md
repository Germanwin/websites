# Ценообразование и упаковка услуги

## Логика тарифной сетки

**Источник:** `доп. материалы` → `Копия_Шаблон_Тарифной_Сетки_2_0_by_surgay_ru.pdf`.

Услуга упаковывается в **три готовых пакета**, от базового к максимальному. Клиент
выбирает не «делать / не делать», а «какой вариант». Срок разработки во всех трёх —
**60 дней**, отличается только состав.

| Пакет | Состав | Цена |
|---|---|---|
| **Базовый** — «Исследование + Landing Page» | Экспресс-исследование + Лендинг-Атлант под ключ | **69 000 ₽ / мес** |
| **Средний** — «LP + мультиквизы + 1 канал трафика + SMM» | Исследование, Лендинг-Атлант, 3 мультиквиза, Яндекс.Директ + ретаргет РСЯ, SMM в 1 сети | **139 000 ₽ / мес** |
| **Максимальный** | Полное исследование, Лендинг-Атлант, мультиквизы, 3 канала трафика (таргет ВК + ретаргет ВК/Директ + контекст), SMM в 2 сетях, прогрев на агрегаторах, автоворонка (чат-бот), усиление продаж | **279 000 ₽ / мес** |

процессное существительное, которое можно поставить в смету и в КП.

### Промпт для генерации состава услуги под свою нишу

В шаблоне лежит рабочий промпт — им состав пакета собирается под любую нишу за минуту:

> Ты топовый директор по маркетингу. Напиши 15 пунктов, которые необходимо выполнить
> для услуги «Разработка продающего сайта в нише строительство загородных домов».
> Пиши в виде процессных существительных, таких как «разработка», «создание»,
> «исследование» и т. п. Не используй глаголы («сделать», «запустить»), каждый из пунктов
> раскрой детальнее — от 3 до 7 пунктов в каждую подуслугу. Я составлю из этого
> предложение рынку. Поэтому добавь уникальности там, где «как у всех». Чтобы было
> не просто «исследование аудитории». Хорошо, когда это «Двухэтапное исследование ЦА
> по методу персонажей с описанием их JTBD».

Ключевая мысль: **воспринимаемая ценность услуги = детализация её состава**. Одна строка
«разработка сайта» и тридцать строк с процессами — это одна и та же работа за разные деньги.

### Кэшбэк с рекламных бюджетов

В шаблоне указан реферальный сервис **vitamin.tools** — возврат **4–9% рекламного
бюджета**. Бюджеты клиентов проходят через твой аккаунт, часть возврата можно отдавать
клиенту как дополнительный аргумент, часть оставлять себе. Это отдельная статья дохода
при работе с трафиком, не требующая продаж.

| **Мобильная версия прототипа** | **+30% к стоимости прототипа** |
| **Мобильная версия к существующему сайту клиента** | Лёгкая входная услуга: основной сайт переделывать не надо |
| Дизайн по готовому прототипу | |
| Сборка/вёрстка | |
| Квиз (Marquiz/Flexbe) | Быстро, высокая ценность |
| Настройка аналитики и целей | Часто «забытая» и потому продаваемая |
| Аудит существующего сайта | Классический вход в клиента |

Ориентир из курса: прототип 89 000 ₽ / 115 000 ₽ с мобильной версией.
Реальную цену ставь от рынка и своего уровня — но **не продавай прототип как
бесплатное приложение к дизайну**: это отдельная интеллектуальная работа.

## Безопасный заход для новичка

«Сделаю мобильную версию вашего сайта, заплатишь по результату» — низкий риск для
клиента, быстрый вход, дальше апсейл на полный сайт.

## Связка с продажами

Полный цикл продажи услуги (поиск клиентов, скрипты, встреча, КП, смета, договор)
живёт в скилле **`sales-machine`** и базе `sales-system/knowledge-base/`.
Здесь — только то, что касается упаковки самой услуги сайта.

Шаблоны: `sales-system/00-source/доп-материалы/` — КП, смета, медиаплан, клиентская
база, CRM, тарифная сетка.
