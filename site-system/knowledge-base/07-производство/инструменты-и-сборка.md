## Квиз-конструкторы

**Flexbe** и **Marquiz** дают максимальную конверсию именно на квизах и не требуют
долгой разработки. Что важно в обоих:

- Копирование страниц между аккаунтами
- Высокая скорость загрузки — за техничку можно не переживать
- **Статистика по шагам квиза** — сразу видно, где отваливаются люди и какой вопрос
  стал «стеной с колючей проволокой»

Собранный квиз — самый быстрый способ получить первую работу в портфолио:
когда рука набита, это **полтора часа**. Порядок: написать оффер по формуле →
придумать мощный призыв к действию → подобрать картинку → собрать.

## Сборка на Flexbe — быстрый путь

1. Регистрация → создать «Квиз»
2. **Логотип, слоган, контакты, кнопка обратного звонка** в шапке
   (кнопка обратного звонка требует отдельной формы: шестерёнка → Выбрать окно →
   Добавить окно → Стандартная форма)
3. **Оффер на первом экране** по формуле
4. Блоки лендинга
5. **Квиз:** заранее знать вопросы; 4–6 вопросов; картинки только там, где нужна
   визуализация; контакт в два этапа — сначала «Куда вам удобно получить расчёт?»
   (галочки), потом поле телефона
6. **Страница «Спасибо»**: заголовок, файл на скачивание (лид-магнит),
   изображение или видеообращение руководителя. Привязывается через
   Квиз → Настройки → Результаты → Перейти по ссылке → выбрать страницу
7. **Подвал:** контакты, реквизиты, политика конфиденциальности
8. **Домен:** Настройки → Домен → добавить/зарегистрировать → проверить
9. **Мобильная версия:** Страницы → Главная → ⋯ → Дублировать → адрес `mobile`,
   дальше сокращаем до 10–12 блоков по [правилам](../05-прототип-и-мобайл/мобильная-версия.md)
10. **Аналитика и цели** — см. [Цели и метрики](../06-запуск-и-аналитика/цели-и-метрики.md)
11. **Проверка** по [чек-листу приёмки](../../checklists/приёмка-сайта.md)
12. Только после этого — трафик

## Если сайт кодится, а не собирается в конструкторе

Порядок тот же — меняется только этап реализации. Что важно сохранить:

- **Дизайн-токены** из мини-гайдлайна: цвета, шкала кеглей, шаг отступов 8 px,
  радиусы, тени
- **12-колоночная сетка**, контейнер 1140–1200 px
- **Производительность:** LCP ≤ 2,5 с, изображения в WebP/AVIF с `width`/`height`,
  ленивая загрузка ниже первого экрана, шрифты с `font-display: swap` и
  предзагрузкой, критический CSS инлайном
- **Sticky-панель CTA на мобильных**
- **Формы:** нативная валидация, `inputmode="tel"`, автозаполнение, без маски ввода,
  галочка согласия на обработку ПД
- **Доступность:** контраст ≥ 4,5:1, фокус-стили, alt у изображений, семантические теги
- **Аналитика:** события на открытие квиза, шаги, отправку формы, клик по телефону
  и мессенджерам

Стек по умолчанию для быстрой сборки: статический HTML + Tailwind либо Next.js
(app router) со статической генерацией. Для визуального слоя и компонентов
использовать скилл `ui-ux-pro-max`.

## Быстрые сроки

| Этап | Время |
|---|---|
| Бриф + анализ ЦА и конкурентов | 1–2 дня |
| Оффер + смысловая карта | 0,5 дня |
| Прототип ПК | 1–2 дня |
| Прототип мобильной | 0,5 дня |
| Дизайн | 2–4 дня |
| Сборка + аналитика | 1–2 дня |

Итого: **7–14 дней** на полноценный лендинг-Атлант, 1–3 дня на квиз-лендинг
или лид-магнит.
