# База знаний: создание продающих сайтов

Знания из курса Grind University — модули «UX/UI Дизайнер» (дизайн-упаковка бренда +
уроки по сайтам Владимира Сургая) и «Интернет-маркетолог» (основы + Digital PRO):
**8 ч 36 мин видео, 43 презентации, рабочие таблицы, 22 эталонных лендинга**.

**Как пользоваться:** просто спроси Claude — «сделай прототип лендинга для стоматологии»,
«напиши оффер», «проверь мой первый экран», «сделай мобильную версию».
Claude подтянет нужные разделы через скилл **`selling-site`**.

Продажа услуги (поиск клиентов, скрипты, КП, договоры) — отдельная база
`../sales-system/` и скилл **`sales-machine`**.

## Три правила, которые решают всё

1. **Заголовок сильнее всего влияет на конверсию.** Смена оффера даёт рост в 2–8 раз
   и не требует редизайна.
2. **Первый экран смотрят 100%, второй — 20–30%.** Всё главное должно быть на первом.
3. **Факты вместо мнений, цифры вместо прилагательных.** Взрослый человек делает
   вывод сам — дай ему материал для вывода.
