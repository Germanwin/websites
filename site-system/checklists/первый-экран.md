# Чек-лист первого экрана

## 6 вопросов уставшего мужика
- [ ] **Куда я попал?** — логотип + дескриптор
- [ ] **Это то, что я искал?** — релевантное ключевое слово в заголовке
- [ ] **Это новое или я это знаю?** — новизна; никаких общеизвестных цитат и слоганов
- [ ] **Есть для меня интересное?** — выгода в цифрах, акция, подарок
- [ ] **Этому можно доверять?** — настоящее фото, факты, регалии, буллиты
- [ ] **Что делать дальше?** — контрастная кнопка + телефон + «перезвоните мне»

## Четыре ножки стола
- [ ] Заголовок собран по одной из 8 формул, есть некруглые цифры и «за счёт чего»
- [ ] CTA нестрессовый, даёт ценность «на 5 000 ₽»
- [ ] Первый экран вызывает доверие
- [ ] Технически всё работает

## Элементы
- [ ] Шапка занимает **не более 10%** высоты экрана
- [ ] Оффер — самый крупный элемент (правило слона)
- [ ] 3–4 буллита, бьющих в критерии выбора ЦА
- [ ] Кнопка контрастная, цвет ≤ 10% площади экрана
- [ ] Надпись на кнопке релевантна заголовку формы
- [ ] Фото репортажное: процесс / результат / товар лицом (не сток)
- [ ] Есть стрелка или визуальный указатель к кнопке / вниз
- [ ] Телефон реальный, есть кнопка «Перезвоните мне»

## Язык
- [ ] Написано языком аудитории, а не отраслевым жаргоном
- [ ] Нет двух длинных сложных слов подряд
- [ ] Один смысл — один посыл, нет разноплановых сообщений
- [ ] Всё считывается за 6 секунд
