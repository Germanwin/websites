# Чек-лист приёмки сайта перед запуском трафика

## Смыслы
- [ ] Есть анализ ЦА и конкурентов, смысловая карта
- [ ] Оффер собран по одной из 8 формул, прогнан через формулу идеальной выгоды
- [ ] Структура блоков закрывает топ критериев выбора и возражений сегмента
- [ ] Все тексты прошли [чек-лист текста](../knowledge-base/03-копирайтинг/чек-лист-текста.md)
- [ ] Обещание рекламы совпадает с заголовком сайта (релевантность)

## Первый экран
- [ ] Пройден [чек-лист первого экрана](первый-экран.md)

## Конверсия
- [ ] Пройден [чек-лист CTA](cta.md)
- [ ] Формы каждые 2–3 блока, разные
- [ ] Есть страница «Спасибо» с лид-магнитом / следующим шагом

## Доверие
- [ ] Реальные фото, не сток
- [ ] Есть кейсы/примеры работ с цифрами
- [ ] Есть отзывы
- [ ] Есть гарантии и снятие ключевых страхов
- [ ] В подвале реквизиты юрлица, контакты, политика конфиденциальности

## Мобильная версия
- [ ] Пройден [чек-лист мобильной версии](мобильная-версия.md)

## Техника
- [ ] Загрузка ≤ 3 секунд (LCP ≤ 2,5 с)
- [ ] Проверено в Chrome, Safari, Firefox
- [ ] Проверено на реальных телефонах (iOS и Android)
- [ ] Нет битой вёрстки, белых полос, наездов
- [ ] **Телефон настоящий и кликабельный**
- [ ] **Отправлена тестовая заявка с каждой формы** — дошла на почту / в Telegram / CRM
- [ ] Кнопки мессенджеров ведут в нужные аккаунты
- [ ] Favicon, title, description, OG-картинка на месте
- [ ] SSL работает, редиректы с www / http настроены

## Аналитика
- [ ] Счётчик установлен, автоматические цели выключены
- [ ] Включены Вебвизор, карта скроллинга, аналитика форм
- [ ] Цели: открыл квиз, шаги квиза, лид с квиза, отправка формы, клик по телефону,
      клик по мессенджеру
- [ ] Проверено, что цели реально срабатывают

## Юридическое
- [ ] Галочка согласия на обработку персональных данных на всех формах
- [ ] Политика конфиденциальности опубликована и ссылка работает
- [ ] Если есть реклама — учтены требования маркировки
