# Чек-лист мобильной версии (15 пунктов)

- [ ] 1. Оставлено 10–12 самых важных блоков из 15–20
- [ ] 2. Обязательно остались: первый экран с оффером, все формы захвата,
      раскрытие УТП, отзывы/сертификаты
- [ ] 3. Все интерактивные элементы — в зоне большого пальца (низ и центр экрана)
- [ ] 4. Один информационный блок = один экран смартфона
- [ ] 5. Если не влезает — контрастное разграничение между блоками
- [ ] 6. Блоки не перегружены: без полотен текста и сложных оборотов
- [ ] 7. Текст из 10 блоков не втиснут в 5
- [ ] 8. Есть картинки, усиливающие восприятие текста
- [ ] 9. Pop-up окон нет; если есть — форма+оффер+кнопка в один экран, без картинок
- [ ] 10. Кнопка CTA крупная, контрастная, цвет ≤ 10% площади экрана
- [ ] 11. Вся форма захвата с призывом помещается в один экран
- [ ] 12. Много воздуха: интервалы между заголовками, подзаголовками, текстом,
      большой межстрочный даже в списках
- [ ] 13. Слайдеров нет — только спойлеры
- [ ] 14. Есть sticky-кнопки, прикреплённые к низу экрана
- [ ] 15. По всему лендингу расставлены кнопки мессенджеров

## Дизайн
- [ ] Фон монохромный, светлый
- [ ] Оффер крупный и читаемый, картинка не перетягивает внимание
- [ ] Кнопка не уехала на второй экран

## Проверка
- [ ] Открыто на **нескольких реальных телефонах**, не только в адаптиве браузера
- [ ] Нет белых полос справа/сверху
- [ ] Ничего не наезжает друг на друга
- [ ] Проверено на медленном интернете
