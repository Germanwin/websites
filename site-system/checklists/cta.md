# Чек-лист CTA

## 7 составляющих
- [ ] **1. Нестрессовый шаг** — не «Купить», а рассчитать / подобрать / получить / попробовать
- [ ] **2. Ценность «на 5 000 ₽»** — смысловая (что именно получит) и **визуальная** (нарисована)
- [ ] **3. Привлекательное оформление** — контраст ≤10% экрана, белое поле ввода,
      объёмная кнопка, подсветка при наведении
- [ ] **4. Надпись на кнопке = заголовок формы** («Получите аудит» → «Получить аудит»)
- [ ] **5. Понятно, что будет потом** — кто, когда и зачем свяжется
- [ ] **6. Процесс вовлекает** — квиз/калькулятор, прогресс-бар, ползунки
- [ ] **7. Галочка согласия на обработку персональных данных**

## Квиз
- [ ] 4–6 вопросов (максимум 7)
- [ ] Первый вопрос элементарный, от простого к сложному
- [ ] Ползунки / варианты / списки вместо ручного ввода
- [ ] Есть вариант «Не знаю / нужна консультация»
- [ ] На вопрос — не больше 15 секунд
- [ ] Вопрос-прокладка перед телефоном: «Куда отправить расчёт?» (галочки, дефолт отмечен)
- [ ] На последнем шаге ещё раз проговорены бонусы
- [ ] Поле телефона подписано осмысленно, подпись **над** полем
- [ ] Маска ввода не используется
- [ ] Берём **только телефон**, без email и капчи

## По сайту
- [ ] Формы захвата каждые 2–3 блока, если блоков больше 8
- [ ] Формы **разные** и подходят по смыслу к соседнему блоку
- [ ] На мобильных есть sticky-кнопка внизу экрана
- [ ] Есть кнопки мессенджеров по ходу лендинга
