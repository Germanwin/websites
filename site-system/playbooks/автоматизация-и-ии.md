# Плейбук: где ускоряться с ИИ

Что реально можно снять с себя, а что нельзя.

## Можно автоматизировать

| Этап | Как |
|---|---|
| **Расшифровка брифа** | Запись созвона → whisper (`sales-system/scripts/ingest.sh`) → структурированные факты |
| **Извлечение фактов из брифа** | LLM: «выпиши все конкретные факты с цифрами, отдельно — оценочные суждения, к каждому суждению задай уточняющий вопрос» |
| **Гипотезы по ЦА** | LLM генерит боли/страхи/критерии → **обязательно проверить** на отзывах и прозвоне |
| **Анализ конкурентов** | Скриншоты + LLM: «выпиши сильные и слабые решения первого экрана» |
| **Варианты офферов** | Дать LLM формулу + смысловую карту → 10 вариантов → отобрать вручную |
| **Черновики текстов блоков** | По прототипу и смысловой карте → потом чек-лист текста руками |
| **Вопросы квиза** | По нише и параметрам подбора |
| **Мобильная версия прототипа** | Правила сокращения формализованы — LLM режет по ним |
| **Сборка HTML/Tailwind** | По утверждённому прототипу + мини-гайдлайну |
| **Чек-листы приёмки** | Прогон по всем чек-листам как ревью |

## Нельзя автоматизировать

- **Бриф с живым человеком** — докапывание до фактов требует реакции на ответ
- **Проверку фактов** — LLM выдумает цифры, а отвечать за них тебе
- **Выбор реальных фото и организацию съёмки**
- **Финальное решение по офферу** — нужна насмотренность и чувство рынка
- **Продажу и переговоры**

## Ключевые промпты

**Извлечение фактов из брифа:**
```
Вот расшифровка брифа с клиентом. Задача:
1. Выпиши все КОНКРЕТНЫЕ ФАКТЫ с цифрами (годы, сроки, суммы, количества,
   гарантии, материалы) — таблицей: факт | цифра | за счёт чего.
2. Отдельно выпиши все ОЦЕНОЧНЫЕ СУЖДЕНИЯ («быстро», «качественно»,
   «индивидуальный подход»).
3. К каждому суждению сформулируй уточняющий вопрос, чтобы превратить его в факт.
```

**Генерация офферов:**
```
Ниша: <…>. Сегмент ЦА: <…>. Ключевые критерии выбора: <…>.
РКС: <…>. Факты компании: <…>.
Собери 10 вариантов заголовка первого экрана по формуле №<N> из 8 формул офферов.
Каждый — по формуле идеальной выгоды: <польза в цифрах> за счёт <свойства>.
Цифры некруглые. Никаких оценочных суждений.
```

**Ревью текста:**
```
Прогони этот текст по чек-листу: о клиенте, а не о компании; факты вместо мнений;
некруглые цифры; есть «за счёт чего»; абзац ≤4 строк; нет сложных слов подряд;
жирным ≤4 слов. Верни таблицу: пункт | ок/нет | как исправить.
```

**Сокращение до мобильной версии:**
```
Вот прототип на N блоков и карта персонажей. Оставь 10–12 блоков,
обязательно сохранив первый экран с оффером, все формы захвата, раскрытие УТП,
отзывы/сертификаты. Приоритет — блоки, закрывающие топ-10 критериев выбора.
Объясни по каждому удалённому блоку, почему его можно убрать.
```

## Конвейер

Когда шаблоны отлажены, один сайт проходит по конвейеру:
бриф (живой) → расшифровка (авто) → факты (LLM+проверка) → ЦА и конкуренты
(LLM+проверка) → офферы (LLM+отбор) → прототип (руками по шаблону) →
тексты (LLM+чек-лист) → дизайн → сборка → аналитика → приёмка (чек-листы).

Узкое место всегда одно и то же — **качество брифа**. Всё остальное масштабируется.
