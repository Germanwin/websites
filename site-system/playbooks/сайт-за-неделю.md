# Плейбук: продающий сайт за 7 дней

Пошаговый маршрут от «клиент сказал да» до «трафик пошёл». Каждый шаг — со ссылкой
на нужный раздел базы.

## День 1 — Бриф

1. Провести бриф по [шаблону](../templates/бриф-сайта.md).
   Записать разговор.
2. **Докапываться до фактов** на каждом оценочном суждении
   ([как](../knowledge-base/01-исследование/бриф-и-смысловая-карта.md#главный-приём-брифа-докапываться))
3. Запросить: логотип в векторе, реальные фото, отзывы, кейсы, доступы к аналитике
4. Определить, куда должны приходить заявки

**Выход:** расшифровка брифа + список фактов компании с цифрами.

## День 2 — Исследование

1. [Анализ ЦА](../knowledge-base/01-исследование/анализ-ца.md): 2–5 портретов
   по [шаблону](../templates/анализ-ца.md)
2. [Анализ конкурентов](../knowledge-base/01-исследование/анализ-конкурентов.md):
   10–20 сайтов, скриншоты, «что нравится / что не нравится»
3. Определить [ступень лестницы Ханта](../knowledge-base/01-исследование/лестница-ханта.md)
   и [тип сайта](../knowledge-base/02-структура-и-смыслы/типы-сайтов.md)
4. Собрать РКС — как аудитория ищет

**Выход:** [смысловая карта](../templates/смысловая-карта.md).

## День 3 — Оффер и структура

1. Выбрать формулу из [8 формул офферов](../knowledge-base/03-копирайтинг/8-формул-офферов.md)
2. Написать 3–5 вариантов заголовка, прогнать через
   [формулу идеальной выгоды](../knowledge-base/03-копирайтинг/формула-идеальной-выгоды.md)
3. Спроектировать [CTA](../knowledge-base/05-прототип-и-мобайл/призыв-к-действию.md):
   нестрессовый шаг + ценность «на 5 000 ₽» + как её визуализируем
4. Собрать [структуру блоков](../knowledge-base/02-структура-и-смыслы/структура-лендинга.md)
   под топ-10 критериев выбора сегмента

**Выход:** оффер + карта блоков с задачей каждого блока.

## День 4 — Прототип ПК

1. Написать все тексты по [3 правилам копирайтинга](../knowledge-base/03-копирайтинг/три-правила.md)
2. Прогнать через [чек-лист текста](../knowledge-base/03-копирайтинг/чек-лист-текста.md)
3. Собрать [прототип](../templates/прототип-лендинга.md) в Figma
4. Прогнать первый экран по [чек-листу](../checklists/первый-экран.md)
5. **Отправить на утверждение клиенту**

## День 5 — Прототип мобильной + дизайн

1. Сократить до 10–12 блоков по
   [правилам мобильной версии](../knowledge-base/05-прототип-и-мобайл/мобильная-версия.md)
2. ⚠️ Презентовать **отдельно** от ПК-версии
3. Собрать [мини-гайдлайн и ТЗ дизайнеру](../templates/тз-дизайнеру.md)
4. Запустить дизайн

## День 6 — Сборка

1. Собрать на Flexbe / Tilda / в коде
   ([инструменты](../knowledge-base/07-производство/инструменты-и-сборка.md))
2. Собрать квиз: 4–6 вопросов, вопрос-прокладка, только телефон
3. Сделать страницу «Спасибо» с лид-магнитом
4. Подключить домен, SSL, favicon, метатеги

## День 7 — Аналитика, приёмка, запуск

1. Настроить [цели в Метрике](../knowledge-base/06-запуск-и-аналитика/цели-и-метрики.md)
2. Проверить, что цели срабатывают
3. Пройти [чек-лист приёмки](../checklists/приёмка-сайта.md) целиком
4. **Отправить тестовую заявку с каждой формы**
5. Проверить на реальных телефонах
6. Только теперь — включать трафик

## После запуска

- Первые 3 дня — смотреть Вебвизор и аналитику форм каждый день
- Смотреть, на каком шаге квиза отваливаются
- Гипотезы тестировать по одной, начиная с заголовка
  ([порядок](../knowledge-base/06-запуск-и-аналитика/цели-и-метрики.md#ab-тесты-и-гипотезы))
