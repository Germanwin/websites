# Правила работы в этом репозитории

## Скриншоты через headless Chrome

На этой машине Google Chrome активно используется человеком. Запрещено
завершать процессы браузера широкой маской по имени приложения.

**Никогда так:**

```bash
pkill -9 -f "Google Chrome"    # убивает и обычный браузер пользователя
killall "Google Chrome"
```

Это убивает пользовательский Chrome вместе со своими headless-процессами.
Из-за SIGKILL в профиле остаётся протухший `SingletonLock`, и после этого
браузер вообще отказывается запускаться.

**Нужно так** — чистить только свои процессы, по пути своего `--user-data-dir`:

```bash
SC=<свой scratchpad>
PIDS=$(ps -axo pid,command | grep "[C]hrome" | grep -F "$SC" | awk '{print $1}')
[ -n "$PIDS" ] && kill $PIDS 2>/dev/null   # сначала SIGTERM, -9 только если завис
```

Ещё лучше — не убивать вовсе: headless-запуск со `--screenshot` и
`--virtual-time-budget` завершается сам. Убирать процесс нужно только если он
реально завис (висит дольше своего `virtual-time-budget` в разы).

Каждому запуску давай отдельный `--user-data-dir` во временной папке и
никогда не используй профиль пользователя из
`~/Library/Application Support/Google/Chrome`.
